# Prática Extensionista IV

Projeto da disciplina de Prática Extensionista IV.

O projeto é um sistema para barbearia, com foco em agendamento de horários.

## Infraestrutura

Para publicação do sistema será utilizado o Render.

O frontend será publicado como aplicação web, o backend como serviço web e o banco de dados utilizado será PostgreSQL.

O código do projeto ficará no GitHub e o GitHub Actions será utilizado para build e testes antes da publicação.
